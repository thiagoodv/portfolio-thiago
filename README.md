# 💻 Portfólio Pessoal

Este repositório contém o código-fonte do meu portfólio pessoal, desenvolvido para apresentar um pouco sobre mim, minha formação, meus conhecimentos e alguns dos projetos que venho desenvolvendo durante minha trajetória em Engenharia de Software.

O site reúne informações sobre meu aprendizado e minhas experiências com programação e desenvolvimento web, além de apresentar alguns dos trabalhos que já realizei.

---

## 🎯 Objetivo do projeto

O objetivo deste projeto é criar um espaço para apresentar minha trajetória acadêmica, compartilhar projetos e demonstrar os conhecimentos que venho adquirindo ao longo da graduação.

O portfólio também serve como uma forma de acompanhar minha evolução na área de desenvolvimento de software.

---

## 🛠️ Tecnologias utilizadas

As principais tecnologias utilizadas no desenvolvimento do site foram:

- **HTML5** — estruturação e organização do conteúdo.
- **CSS3** — estilização, layout e responsividade.
- **JavaScript** — interatividade e funcionalidades do site.

---

## 📂 Organização do projeto

```text
Portfólio Pessoal/
│
├── index.html
├── style.css
├── script.js
│
└── assets/
    └── imagens utilizadas no site
```

- `index.html`: estrutura principal do site.
- `style.css`: estilos e aparência do site.
- `script.js`: funcionalidades e interações.
- `assets/`: imagens e outros recursos visuais utilizados no projeto.
